# Test media

Small, committed fixtures for the Vitest **unit** tests (`npm test`). Two
subtrees:

- `media/` — tiny clips. `media/tiny.mp4` + `media/tiny.mkv` are the same H.264
  stream in two containers, used by
  `src/renderer/render/decoder/mediaInput.test.ts` to prove MP4/Matroska
  reading parity.
- `mcp/` — `rust-catalog-snapshot.json`, the MCP tool-catalog data fixture
  checked by `src/main/state/__tests__/mcp.catalog-bijection.test.ts` and
  regenerated by `scripts/snapshot-mcp-catalog.mjs`.

Real-codec clips for the media-conformance E2E harness live under
`apps/desktop/e2e/fixtures/media` and are generated (ffmpeg required) by
`apps/desktop/e2e/fixtures/generate-fixtures.mjs` — that media is gitignored and
rebuilt on checkout; see `docs/conformance.md`. `WEFTCUT_TEST_MEDIA` may point
the harness at an alternate fixture directory.

For the full test-layout map (unit / Rust / E2E, and why they're split), see
`docs/agents/testing.md`.
