# Test media

Small media clips used by unit tests. `media/tiny.mp4` + `media/tiny.mkv` are
the same H.264 stream in two containers (used by
`src/render/decoder/mediaInput.test.ts` to prove MP4/Matroska reading parity).

Real-codec clips for the media-conformance E2E harness live under
`apps/desktop/e2e/fixtures/media` and are generated by
`apps/desktop/e2e/fixtures/generate.go`; see `docs/conformance.md`.
`WEFTCUT_TEST_MEDIA` may point the harness at an alternate fixture directory.
