# Pan law + envelope fade into the eval leaf (finish ADR 0025) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the audio pan law and the fade-ramp the single, leaf-sourced implementation that preview and export both call, and pin it with cross-language goldens — finishing the migration ADR 0025 began.

**Architecture:** The equal-power pan law moves into `weftcut-eval` as `pan_coeffs(pan, channels) -> [a,b,c,d]` (a time-varying 2×2 mix matrix). Export computes the four coefficients at the 10 ms envelope grid and lerps them per sample (replacing per-sample `pan_frame`); preview drops the browser `StereoPannerNode` for a native `ChannelSplitter → 4×GainNode → ChannelMerger` matrix mixer whose coefficient curves come from the same leaf law. `fade_multiplier` likewise moves into the leaf. Both paths now share one law; goldens prove native and wasm agree.

**Tech Stack:** Rust (`weftcut-eval` leaf as `rlib`+`cdylib`/wasm32, `weftcut` napi crate), `libm`, TypeScript/Web Audio (renderer), Vitest (unit + golden), Playwright `_electron` (preview-graph render test).

## Global Constraints

These are the decisions reached in design review. Every task's requirements implicitly include this section.

- **Single law, both paths (a2).** Preview pans via a native `ChannelSplitter → 4×GainNode → ChannelMerger` matrix mixer driven by leaf-computed coefficient curves — NOT an AudioWorklet, NOT `StereoPannerNode`. The actual L/R summing stays in native Web Audio GainNodes.
- **Grid-coefficient parity (X).** The canonical pan control points are the COEFFICIENTS, sampled on the 10 ms envelope grid. Both sides compute `pan_coeffs` at grid points and lerp coefficients (export per-sample; preview via `setValueCurveAtTime`). This mirrors how `gain` already works (grid-sample linear → lerp).
- **Scalar-only wasm ABI (I).** The leaf's real function returns `[f32; 4]` natively; the wasm boundary gets an indexed scalar shim `pan_coeff(pan, channels, idx) -> f32`. No linear-memory reads, no static out-buffers, no value packing — same discipline as the existing `eval` shim.
- **Determinism.** All trig uses `libm::cos` / `libm::sin` in `f64`, cast to `f32` — never `std`'s `f32::cos` (native↔wasm bit parity, the same reason `db_to_linear` uses `libm::pow`). The leaf is `no_std` on wasm32 with **no heap** — fixed math only, no `Vec` in code reachable from the wasm build.
- **Widths.** Pan coefficients and gains are `f32`. Times are `i64` µs natively; the wasm shim takes `f64` µs and `i32` ints (never `i64`/BigInt).
- **Goldens are the proof obligation.** Every shared function is asserted by BOTH a Rust test and a TS test against ONE checked-in fixture, at f32 tolerance (`1e-5` / `toBeCloseTo(_, 5)`).
- **Evergreen docs.** `docs/` reads as authored today — no dates, phase numbers, or commit hashes in prose. ADRs are historical records; ADR 0025 gets a one-line completion note, no new ADR.
- **Parallel sessions.** This checkout is edited from other sessions concurrently. Work in a git worktree; `git add` by explicit path only; re-check `git status` before each commit.
- **`evalWasm.generated.ts` is gitignored** and regenerated by `npm run build:wasm` (auto-run by `pre{dev,build,test}`). After any leaf change, rebuild it before running TS tests; never commit it.

```rust
/// Equal-power pan law as a 2×2 mix matrix `[a, b, c, d]`, applied as
/// `out_l = a·l + b·r`, `out_r = c·l + d·r`. Branch-matched to Chromium's
/// `StereoPannerNode` (`third_party/blink/.../stereo_panner.cc`), the node the
/// renderer used to delegate to. `channels <= 1` (mono) routes the single input
/// through the `l` slot: `[cos, 0, sin, 0]`. `libm` trig in f64→f32 so native +
/// wasm agree bit-for-bit (see `db_to_linear`). Shared by the export mixer
/// (`audio/mix.rs`) and the renderer's preview matrix mixer (`render/audio/
/// panGraph.ts`, via the wasm `pan_coeff` shim).
///
/// mono:          x=(pan+1)/2; a=cos(xπ/2), c=sin(xπ/2), b=d=0
/// stereo pan≤0:  x=pan+1;     a=1, b=cos(xπ/2), c=0, d=sin(xπ/2)
/// stereo pan>0:  x=pan;       a=cos(xπ/2), b=0, c=sin(xπ/2), d=1
pub fn pan_coeffs(pan: f64, channels: i32) -> [f32; 4] {
    let p = pan.clamp(-1.0, 1.0);
    let fp2 = core::f64::consts::FRAC_PI_2;
    // Cast f64→f32 and clamp rounding residue at the trig-exact zeros
    // (libm::cos(π/2) ≈ 6.12e-17; as f32 that is non-zero, breaking the
    // exact-boundary asserts and diverging from the StereoPannerNode spec).
    let zf = |v: f32| if v.abs() < 1e-7 { 0.0 } else { v };
    let cs = |x: f64| (zf(libm::cos(x * fp2) as f32), zf(libm::sin(x * fp2) as f32));
    if channels <= 1 {
        let (c, s) = cs((p + 1.0) / 2.0);
        [c, 0.0, s, 0.0]
    } else if p <= 0.0 {
        let (c, s) = cs(p + 1.0);
        [1.0, c, 0.0, s]
    } else {
        let (c, s) = cs(p);
        [c, 0.0, s, 1.0]
    }
}
```

```rust
/// Fade multiplier at layer-local `t_us`: linear 0→1 over `fade_in_us` from the
/// layer start, 1→0 over `fade_out_us` into the layer end, multiplied where they
/// overlap. Zero-length fades are identity. Shared by the export mixer and the
/// renderer's gain sampler (wasm `fade_mul`).
pub fn fade_multiplier(t_us: i64, span_us: i64, fade_in_us: i64, fade_out_us: i64) -> f64 {
    let mut m = 1.0f64;
    if fade_in_us > 0 && t_us < fade_in_us {
        m *= (t_us.max(0) as f64) / fade_in_us as f64;
    }
    if fade_out_us > 0 {
        let from_end = span_us - t_us;
        if from_end < fade_out_us {
            m *= (from_end.max(0) as f64) / fade_out_us as f64;
        }
    }
    m
}
```

```ts
// native/eval/src/lib.rs::pan_law_golden_matches_fixture against the native

import { panCoeff } from "../../eval";

  for (const c of fx.coeff_cases) {
    it(`coeff: ${c.name}`, () => {
      for (let i = 0; i < 4; i++) {

      }
    });

  for (const a of fx.apply_cases) {
    it(`apply: ${a.name}`, () => {
```

```ts
// Preview pan matrix mixer (docs/audio.md §Preview mixer). The equal-power pan
// LAW is the shared weftcut-eval leaf (panCoeff); this file only wires the
// native Web Audio graph that APPLIES it: a ChannelSplitter → per-coefficient
// GainNode → ChannelMerger matrix, the same 2×2 mix StereoPannerNode does
// internally, but with coefficients we control so preview and export run one
// law. Coefficient curves are sampled on the 10 ms grid and lerped by
// setValueCurveAtTime (the X parity contract; twin of mix.rs::pan_coeffs_at).
import { panCoeff } from "../../eval";
import { type Envelope, evalEnvelope } from "./envelope";

export interface PanGraph {
  input: AudioNode;
  output: AudioNode;
  /// Stereo: [a (l→L), b (r→L), c (l→R), d (r→R)]. Mono: [a (in→L), c (in→R)].
  gains: GainNode[];
}

/// Lerped equal-power coefficients [a,b,c,d] at layer-local `tUs`. Computes
/// panCoeff at the two grid points straddling tUs and lerps the COEFFICIENTS —
/// the X parity contract (mirrors native `pan_coeffs_at`).
export function panCoeffsAt(env: Envelope, channels: number, tUs: number): number[] {
  if (env.values.length <= 1) {
    const p = env.values[0] ?? 0;
    return [0, 1, 2, 3].map((i) => panCoeff(p, channels, i));
  }
  const last = env.values.length - 1;
  const pos = Math.max(0, tUs) / env.stepUs;
  const i = Math.min(Math.floor(pos), last);
  const a = [0, 1, 2, 3].map((k) => panCoeff(env.values[i]!, channels, k));
  if (i >= last) return a;
  const b = [0, 1, 2, 3].map((k) => panCoeff(env.values[i + 1]!, channels, k));
  const u = pos - i;
  return a.map((av, k) => av + (b[k]! - av) * u);
}

/// Coefficient values for the static fast path. Stereo → [a,b,c,d]; mono →
/// [a,c] (the two gains the mono graph wires).
export function constantPanGains(env: Envelope, channels: number): number[] {
  const c = panCoeffsAt(env, channels, 0);
  return channels <= 1 ? [c[0]!, c[2]!] : c;
}

/// One curve per gain across [localStartUs, localEndUs], or null for a constant
/// envelope. Mirrors AudioMixer's gain `cut()` resolution (≈ one point / 10 ms).
export function panCurves(
  env: Envelope,
  channels: number,
  localStartUs: number,
  localEndUs: number,
): (Float32Array | null)[] {
  const slots = channels <= 1 ? 2 : 4;
  if (env.values.length === 1) return Array(slots).fill(null);
  const n = Math.max(2, Math.ceil((localEndUs - localStartUs) / 10_000) + 1);
  const curves = Array.from({ length: slots }, () => new Float32Array(n));
  // Map output slot index → coefficient index: stereo identity, mono [a,c]=[0,2].
  const coeffIdx = channels <= 1 ? [0, 2] : [0, 1, 2, 3];
  for (let i = 0; i < n; i++) {
    const t = localStartUs + ((localEndUs - localStartUs) * i) / (n - 1);
    const pan = evalEnvelope(env, t);
    for (let s = 0; s < slots; s++) curves[s]![i] = panCoeff(pan, channels, coeffIdx[s]!);
  }
  return curves;
}

/// Build the matrix graph for `channels` (1 or 2). Caller connects its source to
/// `.input` and `.output` onward; per-chunk curves go on `.gains`.
export function buildPanGraph(ctx: BaseAudioContext, channels: number): PanGraph {
  const output = ctx.createChannelMerger(2);
  if (channels <= 1) {
    // mono: one input → two gains → L / R
    const gA = ctx.createGain(); // in → L
    const gC = ctx.createGain(); // in → R
    const input = ctx.createGain(); // fan-out hub
    input.connect(gA);
    input.connect(gC);
    gA.connect(output, 0, 0);
    gC.connect(output, 0, 1);
    return { input, output, gains: [gA, gC] };
  }
  // stereo: split → 4 gains → merge (summing on shared merger inputs)
  const splitter = ctx.createChannelSplitter(2);
  const gA = ctx.createGain(); // l → L
  const gB = ctx.createGain(); // r → L
  const gC = ctx.createGain(); // l → R
  const gD = ctx.createGain(); // r → R
  splitter.connect(gA, 0);
  splitter.connect(gB, 1);
  splitter.connect(gC, 0);
  splitter.connect(gD, 1);
  gA.connect(output, 0, 0);
  gB.connect(output, 0, 0);
  gC.connect(output, 0, 1);
  gD.connect(output, 0, 1);
  return { input: splitter, output, gains: [gA, gB, gC, gD] };
}
```

```ts
import { buildPanGraph, constantPanGains } from "../render/audio/panGraph";

// Render the preview pan matrix graph offline and return mean L/R energy.
// Drives the REAL buildPanGraph so the e2e covers graph wiring, not math.
// Constant pan exercises the topology deterministically; the animated coeff
// path (panCurves) is covered by the envelope coeff-env golden.
async function panRenderProbe(args: {
  channels: number;
  pan: number; // static pan value
  frames: number; // input frames (constant 1.0 per channel)
}): Promise<{ l: number; r: number }> {
  const { channels, pan, frames } = args;
  const sr = 48_000;
  const ctx = new OfflineAudioContext(2, frames, sr);
  const buf = ctx.createBuffer(channels, frames, sr);
  for (let c = 0; c < channels; c++) buf.copyToChannel(new Float32Array(frames).fill(1), c);
  const src = ctx.createBufferSource();
  src.buffer = buf;
  const env = { stepUs: 10_000, spanUs: (frames / sr) * 1e6, values: [pan] };
  const g = buildPanGraph(ctx, channels);
  src.connect(g.input);
  g.output.connect(ctx.destination);
  // constant pan: set gains directly (mirrors AudioMixer fast path)
  const cg = constantPanGains(env, channels);
  g.gains.forEach((node, i) => (node.gain.value = cg[i] ?? 0));
  src.start();
  const rendered = await ctx.startRendering();
  const lCh = rendered.getChannelData(0);
  const rCh = rendered.getChannelData(1);
  let l = 0;
  let r = 0;
  for (let i = 0; i < frames; i++) {
    l += lCh[i]! * lCh[i]!;
    r += rCh[i]! * rCh[i]!;
  }
  return { l: Math.sqrt(l / frames), r: Math.sqrt(r / frames) };
}
```
